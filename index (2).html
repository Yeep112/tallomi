手機版怎麼用

  1. 第一次開啟要下載約 15 MB，等畫面出現「總覽」。之後沒有網路也能記帳。
  2. 加到主畫面：iPhone 按 Safari 下方的「分享」→「加入主畫面」；Android 按瀏覽器選單的「安裝應用程式」。之後都從主畫面的圖示開啟。
  3. 到「設定 → PIN 鎖」可以設定 PIN，也可以再開啟 Face ID／指紋解鎖，都能隨時關閉。
  4. 帳本只存在你的手機裡，不會傳給任何人。請定期到「設定 → 備份與匯出」按「下載備份檔」，存到「檔案」或雲端硬碟。

換手機、清除瀏覽資料，或 iPhone 長時間沒開（沒有加到主畫面時），帳本都可能消失，所以備份很重要。有新版本時，畫面下方會出現「立即更新」，按一下就好，帳本不受影響。

匯率與股價需要網路，而且手機瀏覽器擋掉了部分資料來源，查不到時請手動輸入；Google 試算表同步只有電腦版有。

    安裝步驟

    1. 電腦要先裝好 Python 3.12 或 3.13（到 python.org 下載，安裝時勾選「py launcher」）。
    2. 把下載的壓縮檔解壓縮（在檔案上按右鍵 → 全部解壓縮）。
    3. 在解壓縮後的資料夾，連按兩下 install_pennyworth.bat，等它跑完（第一次約一分鐘）。
    4. 桌面會出現蜂巢 T 圖示的 Tallomi 捷徑，連按兩下就能開始記帳。

    第一次執行時，Windows 可能跳出「Windows 已保護您的電腦」。這是因為程式還沒有購買數位簽章。請按「其他資訊」→「仍要執行」。

    之後的更新會在電腦連網時自動下載，下次開啟時套用；更新前會先備份你的帳本。沒有網路時照常使用。
